# 酒狐画廊

东方小女仆（Touhou Little Maid）模组里的酒狐，一组 AI 绘图实验：在 Minecraft 机械动力里搭出真正运转的蛋糕工厂，截图后交给 GPT 重绘，以及更早几轮用 Qwen-Image-2.1 生成的图。

在线浏览：https://qwert-xx.github.io/winefox-gallery/

本仓库的插画均由 AI 生成（Qwen-Image-2.1、GPT 图像模型）；游戏截图、模型渲染和模组挂画除外，页面里已注明。酒狐角色属于东方小女仆模组及其作者，Steve 属于 Mojang；v18 的动作参考来自 B 站 UP 主 Wone_J 的动画《辛勤工作的酒狐》（BV1qK6QBrEyd）。非商业同人，转载请注明出处。
